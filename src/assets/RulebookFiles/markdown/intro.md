# Introduction

&ensp; Welcome to the RPG-hell rulebook! this page will serve as your starting point in this Tabletop Roleplaying Game. This game is still in active development so polish and fluff aren't the active priority; expect more words here in the future. I would recommend starting by reading the Core Rules.

## What's New?

### New Rule Changes

&ensp; Big updates! We recently shipped a huge overhaul to you build characters. You now select what we call "Paths" which give you pools of Arts and Traits. We also changed stats around a bit. Thieving is gone with Finesse taking it's place, and Medicine and Crafting have been phased out. But don't worry, most of the options that you know and love still exist in some form in the paths that we have made and you can still make wonderfully unique and flavorful characters with this new system (it's better than before!).

### Website Quality of Life

&ensp; There are new huge features we've been working on that you can check out now! If you check out the **Characters** button on the top bar you can now build your own characters with an interactive wizard we cooked up! As of writing it's still in progress so please bear with us. As you go about making a character you'll notice many words are underlined, this is the new glossary tooltip system! This should make it easier to remember all of the important keywords. You can use it from basically anywhere so you'll never have to go searching for information again... But if you do... There's a new shiny search bar in the top left! You should be able to find anything that's not tooltipped or anything on your mind in there, go wild.
